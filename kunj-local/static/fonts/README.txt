Apni font files isi folder mein daal do — .woff2, .woff, .ttf, ya .otf
chalega. Jo bhi naam file ko doge (jaise "Poppins-Bold.ttf" ya
"Bebas Neue.woff2"), wahi naam "select font" dropdown mein dikhega
(dashes/underscores automatically space mein convert ho jaate hain).

Koi code change nahi karna — files daalte hi website khud detect kar
legi.
